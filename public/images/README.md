# Images Directory

Place your images here:

- `owner.jpg` or `owner.png` - Owner/Founder photo for the hero section
- `pte-course.jpg` - PTE course thumbnail
- `ielts-course.jpg` - IELTS course thumbnail
- `spoken-english-course.jpg` - Spoken English course thumbnail
- `video-placeholder.jpg` - Video player placeholder

## Recommended Image Sizes:

- Owner photo: 800x800px (square, will be displayed in a circle)
- Course thumbnails: 1200x800px (landscape)
- Video placeholder: 1920x1080px (16:9 aspect ratio)

## Image Optimization:

For best performance, optimize your images before uploading:
- Use WebP format when possible
- Compress images to reduce file size
- Use appropriate dimensions (don't upload oversized images)
