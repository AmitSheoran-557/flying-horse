# Gallery Photos

Place gallery photos in this directory with the following naming convention:

## Academy Photos
- `academy1.jpg` - Main Reception Area
- `academy2.jpg` - Modern Classrooms
- `academy3.jpg` - Computer Lab
- `academy4.jpg` - Library & Study Area
- `academy5.jpg` - Consultation Rooms
- `academy6.jpg` - Student Lounge

## Class Photos
- `class1.jpg` - IELTS Speaking Class
- `class2.jpg` - PTE Training Session
- `class3.jpg` - Group Discussion
- `class4.jpg` - Writing Workshop
- `class5.jpg` - Mock Test Session
- `class6.jpg` - One-on-One Coaching

## Event Photos
- `event1.jpg` - Success Celebration
- `event2.jpg` - Orientation Day
- `event3.jpg` - Workshop Seminar
- `event4.jpg` - Award Ceremony

## Image Requirements
- Format: JPG or PNG
- Recommended size: 1200x1200px (square for gallery grid)
- Maximum file size: 1MB
- High quality, well-lit photos
