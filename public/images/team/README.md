# Team Member Photos

Place team member photos in this directory with the following naming convention:

- `member1.jpg` - Founder & CEO
- `member2.jpg` - Head of Training
- `member3.jpg` - Senior Visa Consultant
- `member4.jpg` - English Language Trainer
- `member5.jpg` - PTE Specialist
- `member6.jpg` - Student Counselor

## Image Requirements
- Format: JPG or PNG
- Recommended size: 800x800px (square)
- Maximum file size: 500KB
- Professional headshots preferred
